#Infra #개념 #On-premises


## 1. 스토리지가 뭔지부터

- 컴퓨터 안에는 **저장공간(SSD, HDD)**이 있지?
- 서버도 마찬가지로 데이터 저장하려면 디스크가 필요해.
- 그런데 기업 데이터센터는 서버가 수십~수백 대라서, **각 서버마다 디스크를 따로 관리하면 너무 힘들어.**

👉 그래서 **공유 스토리지**라는 걸 만듦 → 여러 서버가 같은 저장공간을 같이 쓰는 구조.


---


## 2. PowerStore 같은 상용 스토리지

- Dell에서 만든 **전용 스토리지 장비** (비싼 대신 안정적이고, 관리 쉬움).
- 그냥 “스토리지 전용 컴퓨터”라고 생각하면 돼.
- 단점: 비쌈, 확장할 때 제조사 장비만 써야 함(폐쇄적).

---


## 3. Ceph는 뭐냐?

- Ceph는 **소프트웨어로 만드는 스토리지**야.
- Dell PowerStore 같은 전용 장비 없이, **일반 서버 + 하드디스크 여러 개**만 있으면 됨.
- 이 서버들을 네트워크로 묶고 Ceph 소프트웨어를 설치하면, 마치 하나의 큰 스토리지처럼 동작해.

👉 쉽게 말해서:

- **PowerStore** = 비싼 전용 금고
- **Ceph** = 집에 있는 컴퓨터 여러 대를 묶어서 만든 DIY 금고

---


## 4. Ceph의 특징

- 서버가 10대든, 100대든 **확장 가능**
- 데이터가 여러 서버에 자동으로 **복제**돼서, 한 서버가 고장 나도 데이터가 안전함
- 블록(디스크), 파일(NFS 같은 공유폴더), 오브젝트(AWS S3 같은 방식) **다 지원**

---


## 5. 그림으로


```plain text
[서버1 + 디스크]   [서버2 + 디스크]   [서버3 + 디스크]
        |                  |                  |
        +------------------+------------------+
                       |
                 [ Ceph 소프트웨어 ]
                       |
          서버들이 가진 디스크를 합쳐서
         "하나의 큰 스토리지"로 제공
```


---


👉 정리:

- **PowerStore 1200T** = Dell에서 만든 고급 스토리지 장비
- **Ceph** = 오픈소스 소프트웨어, 일반 서버 여러 대를 묶어 스토리지로 만드는 방식

---


## 1. PowerStore 1200T와 Ceph의 성격 차이

- **PowerStore 1200T**
    - 엔터프라이즈급 상용 스토리지
    - 강점: 안정성, 성능, 지원서비스
    - 단점: 비쌈, 제조사 종속(Dell만 써야 함), 확장 유연성 제한
    - 주용도: DB, ERP, VM웨어 같은 **미션 크리티컬 워크로드**
- **Ceph**
    - 오픈소스 분산 스토리지
    - 강점: 확장성(서버 추가만 하면 용량·성능 확장), 비용 효율, 오브젝트 스토리지(S3 API) 지원
    - 단점: 직접 운영/관리 필요, 성능 튜닝 난이도 있음
    - 주용도: 빅데이터, AI/ML, 백업, 클라우드 네이티브 앱, 내부 S3 서비스

---


## 2. 왜 둘 다 쓰냐?


프로젝트에서는 **용도 분리** 때문에 그래.

- **PowerStore**

    → 기업 핵심 서비스 (DB, VM, 트랜잭션 중요 서비스)에 사용


    → 안정성과 고성능이 중요해서 상용 스토리지가 적합

- **Ceph**

    → 클라우드 환경(OpenStack, Kubernetes 등)에서 오브젝트 스토리지나 대규모 확장 가능한 스토리지 풀 필요할 때 사용


    → 예: 연구 데이터, 로그 저장, 빅데이터, 내부 S3 서비스


---


## 3. 실제 사례

- 은행/대기업:
    - Core Banking DB = PowerStore
    - 모바일 앱 로그, 이미지/영상 저장 = Ceph
- 클라우드 사업자:
    - VM 디스크용 일부 = 상용 스토리지
    - 나머지 대규모 데이터(백업, 고객 파일) = Ceph

---


## 4. 네 프로젝트의 의미


네 프로젝트에서 **PowerStore + Ceph**가 같이 있다는 건:

- 고객사가 **미션 크리티컬 워크로드**(ERP, DB 등)는 PowerStore에 올리고,
- **클라우드 네이티브 워크로드**(VM, 컨테이너, S3 같은 오브젝트 스토리지 서비스)는 Ceph로 운영하려는 것.
